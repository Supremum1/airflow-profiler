Память на операциях

PSS основного процесса задачи: ближайший отсчёт до/после в пределах 1 с и максимум отсчётов внутри вызова. Значения не являются объёмом выделенной операцией памяти.

Качество замеров

Процесс задачи включает Python, библиотеки и код исполнения Airflow. PSS делит общие страницы между процессами. Короткие пики могут быть пропущены. Память cgroup и PSS имеют разные правила учёта.

    CPU контейнера — среднее между отсчётами. Пунктир CPU означает интервал от 4 с. CPU операций измеряется в процессе Python, RSS — изменение его памяти за вызов. CPU процессов — по соседним отсчётам; старт и завершение между ними могут быть пропущены. PSS и память cgroup имеют разные правила учёта: их нельзя вычитать для вычисления расходов Airflow.
